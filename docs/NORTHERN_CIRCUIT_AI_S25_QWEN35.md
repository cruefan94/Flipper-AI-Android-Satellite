# Northern Circuit AI — Galaxy S25 offline models (development)

## Hardware direction (owner's current phone)
- Primary phone: Samsung Galaxy S25 (Canadian SM-S931W; 12 GB physical RAM class).\n- RAM Plus is enabled/configurable up to 8 GB on this phone. It uses storage-backed virtual memory, **not 8 GB additional physical RAM**. Do not count it as fast model RAM or use it to justify loading a much larger model; monitor Android memory pressure and thermals.
- Start with **Qwen3.5-4B Q4_K_M GGUF** (approx. 2.7–3.0 GB for weights). The GGUF runtime also needs RAM for KV cache, Android and app processes.
- If too slow, unstable, or memory-constrained, use **Qwen3.5-2B Q4_K_M** (approx. 1.3–1.5 GB).
- Keep the already installed Qwen3-0.6B LiteRT as backup. **Do not import GGUF as .litertlm.**
- Phone model and RAM are manufacturer specifications, not a measured device allocation or inference speed.

## Verified software interfaces in this repository
- Android Satellite already supports an optional **Termux llama.cpp OpenAI-compatible server** at `http://127.0.0.1:9931/v1/chat/completions`.
- Existing client uses the model alias `flipper-local`. Launch the server with the same alias so the Android app needs no endpoint changes.
- The embedded Google LiteRT-LM 0.18.0 path only imports compatible `.litertlm` weights, not GGUF. Qwen3.5 is **not** asserted compatible with that pinned embedded runtime.
- No new cloud service or Worker, no network listener beyond localhost, no autonomous device commands.

## Android S25: initial no-root Termux setup
1. Install an up-to-date official Termux from https://github.com/termux/termux-app/releases or F-Droid. Avoid the obsolete Play Store package.
2. Open Termux and enter:
   ```sh
   pkg update -y
   pkg install -y llama-cpp curl
   ```
3. To launch **4B** (a one-time download from Hugging Face may occur):
   ```sh
   llama-server -hf ggml-org/Qwen3.5-4B-GGUF:Q4_K_M --alias flipper-local --host 127.0.0.1 --port 9931 -c 2048 -t 4
   ```
4. If 4B fails to fit or is too slow, stop with Ctrl+C, then run **2B** instead:
   ```sh
   llama-server -hf gguf/Qwen3.5-2B-GGUF:Q4_K_M --alias flipper-local --host 127.0.0.1 --port 9931 -c 2048 -t 4
   ```
5. In Android Satellite **MODELS** screen select **USE LLAMA.CPP (TERMUX SERVER)** and press **TEST LLAMA.CPP SERVER**.
6. The response must be generated by the active local server (not a diagnostic greeting). Keep cloud consent OFF for local-only tests.
7. Leave Termux running while chatting; Android background restrictions may stop the server. No automatic background service is created.

**Known limitations:** Termux's packaged `llama-cpp` may lag new Qwen3.5 architecture support. If the server prints an unsupported-model error, do not change or erase the existing model. Update the package or assess an upstream build. Startup time, RAM use, Android background operation and actual output must be verified on the user's S25. `--ctx-size 2048` is deliberately conservative for initial measurements.
