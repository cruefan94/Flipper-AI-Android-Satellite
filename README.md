# Flipper AI Android Satellite — public APK build mirror

Android-only build mirror of the private Flipper AI Momentum project. No Momentum firmware, ESP32-S2 source, private configuration, API credentials or model weights are intended to be published here.

**Development status:** source migration and security review in progress. No working APK is claimed until CI completes successfully. Do not enter credentials into development builds.

Source is mirrored from the primary project's `feature/ble-ai-satellite-v06` branch. The private project remains the authoritative source.
